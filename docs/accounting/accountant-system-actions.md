# دليل المحاسب

هذا الدليل لسيارة النولون وسيارة العقد. الاثنان نفس القيود. لا سعر خاص بالعقد.

مثال واحد بأرقام ثابتة، لمصنع وطنيه. نفس الخطوات لأي عميل. الذي يتغير هو سعر الطن فقط.

القيد يُفتح مرة واحدة. الحفظ مرة ثانية، أو إصدار الفاتورة مرة ثانية، لا يكرر القيد. الطباعة لا تفتح قيداً. المبلغ صفر لا يُكتب.

## الأرقام

سعر الطن لمصنع وطنيه = مطالبة 100 + سعر الطن 500 + ضريبة الشيت 70 = **670**.

الإيراد = وزن الدفتر 18.5 × 670 = **12395**.

نولون الشيت **8000**. العهدة المسلّمة على الرحلة **2000**. يبقى للمورد **6000**.

ضريبة المنبع = 12395 × 3% = **371.85**.
ضريبة القيمة المضافة، إن فُتح الخيار = 12395 × 14% = **1735.30**.

لمصنع العريش سعر الطن هو سعر نوع التعبئة. مثال: سايب 750. باقي القيود لا يتغير.

## 1. طلب العهدة

الطلب وحده لا يعمل شيئاً. القيد يُفتح عند **القبول**.

المال يخرج من الخزينة ويدخل عهدة الموظف.

|      | الحساب      | المبلغ |
| ---- | ----------- | ------ |
| مدين | عهدة الموظف | 2000   |
| دائن | الخزينة     | 2000   |

لو العهدة من موظف لموظف: مدين عهدة المستلم، ودائن عهدة المسلّم.

## 2. حفظ الرحلة

لا قيد. الإيراد الفعلي ما زال فارغاً.

## 3. حفظ البوليصة

هنا يُحسب الإيراد **12395**، وتُفتح القيود.

المحافظة ومنطقة التسليم تُختاران في البوليصة. من غيرهما لا إيراد ولا قيد.

مورد النقل لازم يكون من فرع الموظف الذي أنشأ الرحلة.

**الإيراد**

|      | الحساب                           | المبلغ |
| ---- | -------------------------------- | ------ |
| مدين | العملاء تحت التنفيذ ← مصنع وطنيه | 12395  |
| دائن | ايرادات تحت التنفيذ ← مصنع وطنيه | 12395  |

**النولون** — نولون الشيت بعد طرح العهدة:

|      | الحساب                  | المبلغ |
| ---- | ----------------------- | ------ |
| مدين | سيارات عقود النولون     | 6000   |
| دائن | مورد النقل ← مورد النيل | 6000   |

**العهدة** — ما سُلّم على الرحلة:

|      | الحساب                  | المبلغ |
| ---- | ----------------------- | ------ |
| مدين | مورد النقل ← مورد النيل | 2000   |
| دائن | عهدة المكتب             | 2000   |

المجموع 20395 مدين و 20395 دائن.

لو في عهدة من مورد، وبمبلغ أكبر من صفر: مدين مورد النقل، ودائن مورد العهدة. الصفر لا يُكتب.

## 4. الفاتورة

من الرحلات اختر رحلات **عميل واحد**، حالتها تم تحصيل البوليصة، ثم إصدار.

الأساس هو الإيراد المرحّل: **12395**.

### بلا ضريبة قيمة مضافة

المنبع يُحسب دائماً: **371.85**. الصافي = 12395 − 371.85 = **12023.15**.

| الحركة | الحساب                           | المبلغ   |
| ------ | -------------------------------- | -------- |
| مدين   | ايرادات تحت التنفيذ ← مصنع وطنيه | 12395    |
| دائن   | ايرادات تم تنفيذها ← مصنع وطنيه  | 12395    |
| دائن   | العملاء تحت التنفيذ ← مصنع وطنيه | 12395    |
| مدين   | ضرائب منبع                       | 371.85   |
| مدين   | عملاء ← مصنع وطنيه               | 12023.15 |

المدين 24790 والدائن 24790.

### بالضريبة

نفس الأسطر، ويُضاف:

| الحركة | الحساب               | المبلغ   |
| ------ | -------------------- | -------- |
| دائن   | ضريبة القيمة المضافة | 1735.30  |
| مدين   | عملاء ← مصنع وطنيه   | 13758.45 |

الصافي هنا = 12395 + 1735.30 − 371.85.

المدين والدائن 26525.30.

بعد الإصدار الحالة **تم اصدار فاتوره**. تحت التنفيذ ينقص 12395.

الطباعة تعرض المنبع والصافي، ومع الضريبة تعرض المضافة. لا قيد من الطباعة.

## 5. مطالبة الخدمات

لكل العملاء. الزر: **طباعة مطالبة الخدمات**.

ورقة للسولار والكارتات والموازين. السعر من عمود المطالبة في شيت العميل. لا قيد.

## ما لا يتحول إلى قيد

- حفظ الرحلة قبل البوليصة
- الوقود والرسوم، إلا بقيد يكتبه المحاسب بنفسه
- الطباعة
- أي مبلغ صفر
